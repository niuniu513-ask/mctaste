主持人备餐单

请由不参与评分的主持人准备。去掉包装、使用相同容器，按编号分装。先确认参与者的忌口与过敏原，盲评不隐藏饮食风险。

评分前请关掉此页，避免提前看到答案。

换一份真实餐品清单

在本机用官方 MCP 同步门店在售菜单与营养数据，再刷新页面。这里不接收 Token，浏览器也不直连外部域。

set MCD_MCP_TOKEN=你的令牌
node scripts/mcp.mjs sync --config data/capture.json

同步会生成餐品清单与营养数据（揭晓页自动显示「营养真相」）。也可导入标准格式文件，手动文件统一标为“未独立核验”。

重新开始这一局？

当前分组和评分将清除，餐品清单会保留。
