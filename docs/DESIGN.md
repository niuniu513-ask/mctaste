# 麦麦盲评局设计

为朋友、家庭和小团队组织 3–6 款餐品的线下盲评。页面唯一目标是完成一次能解释结果的盲评。

颜色：暖白 #FFFDF6、金拱门红 #DA291C、深棕 #33200F、金黄 #FFC72C、奶油 #FFF3D1、浅棕线 #F0E0BD（2026-10-22 由蓝黄实验风改为麦当劳红黄品牌主题，主色变量仍沿用 --blue 命名以减少改动面）。
字体：展示字使用 Microsoft YaHei UI / 微软雅黑的粗体；正文使用系统中文无衬线；样本编号使用 Consolas 等宽字体。不请求在线字体。

布局：顶部简洁品牌与三个阶段；首屏大标题与一张倾斜的匿名样本卡；下方选品区与右侧建局票据。盲评期间收起商品身份，页面保留当前样本、三个评分维度与身份竞猜。揭晓以排名、金舌头战报和分布为主。

辨识元素是一张红色孔边匿名样本卡，背面是餐品，正面只有编号与感官线条；卡片后方衬一枚倾斜的金拱门水印，品牌图标同为红底金拱门。避免用餐品图片在盲评时泄露身份。周边不添加装饰性图表。

选品区与揭晓榜使用真实餐品照片（2026-10-22 更新，替代原通用 SVG 插画）：图片取自麦当劳中国官网「产品图片」媒体页（mcdonalds.com.cn/media/product），下载为本地副本存放于 public/img/，按官网图库数字 ID 命名，不外链、不进入投票页——盲评中评委只看编号。SVG 插画保留作加载失败与手动导入清单的兜底。照片卡片带轻微交替倾斜与悬停缩放，避免整齐划一的模板感。

初稿曾用蓝黄实验记录本风格，2026-10-22 按产品决策改为麦当劳红黄品牌主题。页面装饰性英文小字已全部移除，仅保留样本编号（M01）与浏览器标签里的品牌名。移动端改为单列；键盘焦点可见；动效遵循 prefers-reduced-motion。
